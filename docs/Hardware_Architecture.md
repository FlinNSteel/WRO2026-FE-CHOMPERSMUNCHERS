# Hardware and Components 
This section will describe all hardware components and their purpose. All our components are from the LEGO® Education
SPIKE™ Prime set. 
## 1. Main Unit 
### Technic™ Large Hub
* **Quantity:** 1
* **Description:** The Hub is a programmable control unit that LEGO® sensors and motors can be attached to. It has an intuitive light and button interface and can work autonomously or in streaming mode.
* **Features:**
  * 6 input/output ports
  * 5×5 LED light matrix
  * 6-axis gyroscope
  * Bluetooth connectivity
  * Built-in speaker
  * Rechargeable battery

## 2. Motors
### Technic™ Large Angular Motor
* **Quantity:** 1
* **Description:** The motor is designed to function in models as both a motor and sensor. With the
integrated advanced Rotation Sensor, the motor can report both speed and position. It can also sense direct user input if the output is rotated by hand.
* **Features:**
  * Built-in rotation sensor
  * Precise movement control
  * Position and speed can be programmed
  * High torque
  * Suitable for driving wheels and larger mechanisms
<img src="https://i.postimg.cc/htYc3FMX/Large-Angular-Motor.png" width="50%" height="50%">

### Technic™ Medium Angular Motor
* **Quantity:** 1
* **Description:** The motor is designed to function in as both a motor and sensor. With the integrated advanced Rotation Sensor, the motor can report both speed and position. It can also sense direct user input measures if the output is rotated by hand.
* **Features:**
  * Built-in rotation sensor
  * Precise movement control
  * Programmable speed and position
  * Faster than the Large Angular Motor
  * Suitable for smaller mechanisms and attachments
<img src="https://i.postimg.cc/rwXvd8hR/Medium-Angular-Motor.png" width="50%" height="50%">

## 2. Sensors
### Technic™ Distance Sensor
* **Quantity:** 2
* **Description:** The Distance Sensor uses ultrasonic technology to detect objects and measure how far away they are, helping the robot navigate and avoid obstacles.
* **Features:**
  * Detects objects in front of the robot
  * Measures distance
  * Can detect obstacles
  * Includes a programmable LED
<img src="https://i.postimg.cc/1z29jxmW/Distance-Sensor.png" width="50%" height="50%">

### Technic™ Color Sensor
* **Quantity:** 1
* **Description:** The Color Sensor detects colors and measures the amount of reflected light, allowing the robot to react to different colors and surfaces.
* **Features:**
  * Detects 6 colors
  * Measures reflected light
  * Measures ambient light
  * Detects light intensity
  * Can help robots follow colored lines 
<img src="https://i.postimg.cc/sX4pJJyB/Color-Sensor.png" width="50%" height="50%">
